# Motorcycle overlap and plate ownership

## Baseline

The existing project work was committed and pushed to `main` as `74f5f2f`
before this change. Model weights, raw datasets and local configuration remain
local under the project's existing exclusions. This change does not train or
overwrite models. The current `.env` selects v5; it was preserved. Regression
checks explicitly select v4 in an isolated process and database.

## Problem

When a front motorcycle disappears from the detector during vertical alignment,
its rider can geometrically match the rear motorcycle. A track can also switch
motorcycles, contaminating the buffered plate crops. OCR then selects a clear
crop from the wrong motorcycle. Changing OCR alone cannot fix that ownership
error. A smaller sample interval also supplies more opportunities to duplicate
votes and fragment tracks.

## Changes

- Match tracks and plates jointly with one-to-one assignment and an unmatched
  option. Retain the high/low confidence tracking stages.
- Associate riders after tracking. Reject ambiguous overlap and implausible
  rider positions relative to the motorcycle, including when the front bike is
  missing. Drivers and passengers may still share one motorcycle.
- Pause evidence collection during ambiguous overlap; freeze tracker appearance
  updates there. Use clothing context, colour and brightness for matching.
- Limit lost-track extrapolation, expire stale tracks before matching, and allow
  a short, appearance-supported first motion step for fast new tracks.
- Require matching rear anchors before aliasing duplicate motorcycle boxes.
- Count independent observations at least 0.2 seconds apart. Check plate
  position and size relative to the bike before buffering crops.
- Reject plate appearance changes against an original colour anchor. Measure
  colour inside the detector box, excluding the surrounding bodywork included
  in OCR crops. Matching colour is only a necessary check, not proof of identity.

All rules use geometry, time or appearance. There are no video-name, plate-number
or camera-coordinate exceptions.

## Validation

`python -m unittest discover -s backend/tests`: **53 tests passed**. Coverage
includes crossing ambiguity, missing front bikes at multiple scales, passengers,
one-to-one matching, dense votes, stale tracks, plate-buffer contamination,
appearance freezing and recovery. Existing OCR and playback tests pass.

Full detector/tracker/PaddleOCR checks are in
`analysis/overlap-fix/validated-pipeline/results.json`, generated by
`scripts/check_overlap_pipeline.py`. They use full-frame inference and adaptive
sampling; 0.5 and 1 second are the base intervals, not fixed intervals.

| Model / video | Base interval | Result |
|---|---:|---|
| v4 / IMG_6665 | 0.5 s | Two records, with visually checked plate crops 3399 and 3252 |
| v4 / IMG_6665 | 1 s | One record, plate 3252; first passage missed |
| v4 / IMG_6805 | 0.5 s | Three records retained |
| v5 / IMG_6665 | 0.5 s | Two records, plate crops 3399 and 3252 |

The v4 IMG_6665 first record previously acquired plate 3872 from the helmeted
motorcycle. The final 0.5-second check saves 3399 instead. OCR readings still
carry the app's uncertainty status; this is not a claim of reliable Thai OCR.

`scripts/replay_overlap_review.py --name validated --all-clips` replays 27 cases:
three original adaptive runs plus 24 clips at fixed 0.5-second intervals.
Compare `analysis/overlap-fix/baseline/results.json` with
`analysis/overlap-fix/validated/results.json`. Both use the same cached detections.
OCR is disabled and legacy metadata lacks negative-vehicle boxes, so these
replays isolate association behavior rather than measuring complete accuracy.

## Remaining limits

- Sparse observations can still miss a passage or split a fast-moving track.
  The 1-second IMG_6665 run misses the first violation.
- Wider fixed-interval replay is mixed. Additional records in IMG_6776 and
  IMG_6791 include duplicates on visual review. IMG_6805 fixed-interval replay
  drops from two records to one, although its adaptive run retains three.
  IMG_6798 drops from six to four but still has a duplicate and missed riders.
  Raw reductions must not be presented as accuracy gains.
- Overlap rejection deliberately withholds evidence when ownership is ambiguous;
  this can reduce recall. Similar-looking plates can still pass appearance checks,
  and severe illumination changes can reject a correct crop.
- This is an ownership improvement with a demonstrated IMG_6665 correction,
  not a guarantee against all ID switches or a measured overall accuracy gain.

Earlier reports, recordings, datasets and model checkpoints are preserved.
